# Skills

Step-by-step playbooks for recurring work on The Geeky Times. They're plain markdown in the open `SKILL.md` format:
a folder per skill, YAML front matter with `name` and `description`, then instructions. Any agent can use them. Read
the one that matches the task before starting, and follow it.

| Skill | Use it when |
|---|---|
| [convert-paper](convert-paper/SKILL.md) | **Start here** to turn any source into a published story: the whole route, step by step |
| [explain-source](explain-source/SKILL.md) | Turning a research paper or engineering blog post into a story |
| [fact-check](fact-check/SKILL.md) | Verifying evidence numbers, section anchors and `paper`-basis tags |
| [tag-story](tag-story/SKILL.md) | Inferring and reviewing tags for a story |
| [draw-illustrations](draw-illustrations/SKILL.md) | Making comic panels, lead plates and icons in the house style |
| [publish-issue](publish-issue/SKILL.md) | Adding a story to the site and assembling an issue |
| [develop-frontend](develop-frontend/SKILL.md) | Changing the React UI without breaking the data-driven rules |

Background for all of them: `AGENTS.md`, `docs/decisions.md`, `docs/product-plan.md`, `docs/data-model.md`.
